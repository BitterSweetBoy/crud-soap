# CRUD SOAP con PHP

Este proyecto implementa un CRUD (Create, Read, Update, Delete) utilizando el protocolo SOAP con PHP. El CRUD se refiere a las operaciones básicas de manipulación de datos en una base de datos.

## Requisitos

Asegúrate de tener instalado lo siguiente antes de comenzar:

- PHP 7.x o superior
- Servidor web (puede ser Apache, Nginx, etc.)
- Extensión SOAP habilitada en PHP
- Base de datos (MySQL, PostgreSQL, etc.)
